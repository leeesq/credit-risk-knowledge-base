## 跨专题阅读

- **新产品的准入、额度和定价。** 先看产品专题中的借款期限、资金成本和风险约束。再到客群专题确认能取得哪些信息，到策略专题定义第一版准入与模型。额度和定价一旦改动，可回到评估专题，核对谁有资格、谁实际用信、损失窗口是否成熟。主库见[产品要素](../README.md#2-产品要素)与[资产指标](../README.md#4-资产指标)。
- **外部数据接入和模型替换。** 先核对来源、授权、缺失含义和线上可得时间。再区分数据单独能区分谁、在现行策略上实际改变了哪些动作，以及历史上哪些人能观测到还款。对新增放行人群的风险结论，需要和历史可观测结果分开。主库见[数据](../README.md#12-数据)、[效果指标](../README.md#7-效果指标)与[策略和模型](../README.md#11-策略和模型)。
- **上线异常的归因。** 先定位进件、评分和动作哪一步发生变化，再检查对照组和数据时点。表现成熟后，核对排序、通过量和实际损失是否朝同一方向变动。复盘保留业务判断、验证用的样本和工程记录。主库见[运营指标](../README.md#5-运营指标)和[阶段](../README.md#10-阶段)。

文中会区分作者的案例、编者补充的演算和实务检查。涉及监管、市场和平台做法时，以原文对应的年份、地区和产品为背景。应用时按实际场景核对规则与口径。
