## 与知识库对照

- **看一笔业务怎么赚钱。** 把产品和风险经营专题里的额度、定价和回收放在一起读，再核对收益、资金占用和损失的统计期间。见主库的[产品要素](../README.md#2-产品要素)和[资产指标](../README.md#4-资产指标)。
- **从模型分数走到策略动作。** 把策略专题里的决策对象和标签与评估专题里的通过量、成熟风险和线上对照连起来看。见主库的[效果指标](../README.md#7-效果指标)和[策略和模型](../README.md#11-策略和模型)。
- **判断数据能否用在决策上。** 外部数据专题涉及覆盖、授权、调用成本和时点。分析时可以逐项核对哪些记录在审批前已经可用。见主库的[数据](../README.md#12-数据)。

文章跨越不同年份和市场。涉及监管、平台做法、历史数据或作者对行业的判断时，阅读时请结合原文的时间、地区与业务条件。
